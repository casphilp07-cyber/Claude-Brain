# wshobson/agents — Multi-Harness Agentic Plugin Marketplace

**Was es ist:** Ein plattformübergreifender Plugin-Marketplace mit fertigen Subagenten, Skills und Commands, der aus einer einzigen Markdown-Quelle für fünf verschiedene Coding-Harnesses ausgeliefert wird: Claude Code, Codex CLI, Cursor, OpenCode und GitHub Copilot. ~38,4k Sterne, ~4,1k Forks, MIT-Lizenz.

**Kernfunktionen:**
- **94 Plugins, 203 Agenten, 175 Skills, 109 Commands** — granular installierbar, man nimmt nur, was man braucht
- Agenten decken Architektur, Programmiersprachen, Infrastruktur, Security, Daten/ML und Dokumentation ab (Domain-Experten statt Allzweck-Agent)
- **16 Orchestratoren** für Multi-Agent-Koordinationsworkflows
- Wofür einsetzen: schnell ein fertiges Team spezialisierter Subagenten (z.B. Security-Reviewer, Python-Experte, Infra-Architekt) für ein Projekt zusammenstellen, ohne jeden Agenten von Hand zu schreiben — besonders praktisch, wenn man dieselben Konfigurationen auch außerhalb von Claude Code (z.B. Cursor) nutzen will

**Wie man es mit Claude Code nutzt:**
```
/plugin marketplace add wshobson/agents
/plugin install python-development
```
(oder jedes der 94 Plugins einzeln nach Bedarf)

**Einschätzung:** Als Plugin installieren — sehr praxisnah und granular (einzelne Plugins statt Alles-oder-nichts), gute Ergänzung zu Superpowers (dort: Methodik, hier: konkrete Domain-Spezialisten).
