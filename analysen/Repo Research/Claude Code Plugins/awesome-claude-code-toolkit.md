# Awesome Claude Code Toolkit (rohitg00/awesome-claude-code-toolkit)

**Was es ist:** Ein sehr umfangreiches "Alles-in-einem"-Toolkit: 135 Agenten, 35 kuratierte Skills (plus Zugriff auf 400.000+ weitere über einen "SkillKit"-Marktplatz), 176+ Plugins, 42 Commands, 20 Hooks, 15 Rules, 7 Templates, 14 MCP-Configs, 26 Companion-Apps. ~2,4k Sterne, ~863 Forks — deutlich kleiner als die anderen Top-Repos, aber inhaltlich extrem breit.

**Kernfunktionen:**
- Agenten nach Domäne organisiert (Core Development, Sprachen, Infrastruktur, QA, Data/AI, Business, Research)
- Skills + SkillKit-Marktplatz als riesiger Zusatz-Pool
- Wofür einsetzen: als "Fundgrube", wenn man für eine sehr spezifische Nische (ungewöhnliche Sprache, Nischen-Framework) etwas sucht, das die kleineren/kuratierteren Listen nicht abdecken — Breite statt Tiefe

**Wie man es mit Claude Code nutzt:**
```
/plugin marketplace add rohitg00/awesome-claude-code-toolkit
```
Alternativ manuell klonen nach `~/.claude/plugins/claude-code-toolkit` oder per Install-Script (`setup/install.sh`). Agenten/Skills werden dann im eigenen `CLAUDE.md` referenziert, um sie zu aktivieren.

**Einschätzung:** Mit Vorsicht durchstöbern statt blind komplett installieren — bei so einer großen Menge (176+ Plugins, 400k Skills via Marktplatz) und vergleichsweise wenig Community-Validierung (nur 2,4k Sterne) lohnt es sich, einzelne Komponenten gezielt zu prüfen statt alles auf einmal zu aktivieren.
