# Awesome Claude Code (hesreallyhim/awesome-claude-code)

**Was es ist:** Die bekannteste "Awesome List" im Claude-Code-Ökosystem — eine von Hand kuratierte Sammlung der besten Ressourcen rund um Claude Code. ~51,4k Sterne, ~4,5k Forks, sehr aktiv (1.410+ Commits, tägliche Pushes).

**Kernfunktionen:**
- Systematisch katalogisierte und geprüfte Einträge (eigenes `config.yaml` + `generate_readme.py`-System, automatisierte Tests/CI für Qualitätssicherung) statt einer wild gewachsenen Linksammlung
- Deckt die ganze Bandbreite ab: Slash Commands, Subagenten, Skills, Statuslines, Developer-Tooling, Plugins
- Wofür einsetzen: als zentraler Ausgangspunkt, um schnell neue, qualitativ geprüfte Tools/Plugins zu entdecken, statt selbst GitHub zu durchsuchen — quasi ein "Inhaltsverzeichnis" für den Rest dieser Recherche

**Wie man es mit Claude Code nutzt:** Kein installierbares Plugin, sondern ein Nachschlagewerk/Index — man klickt sich zu den dort gelisteten Ressourcen durch und installiert die jeweils gewünschten einzeln.

**Einschätzung:** Übernehmen als laufenden Referenzpunkt (in Obsidian verlinken) — sinnvoll, diesen Ordner hier regelmäßig gegen neue Einträge dort abzugleichen, statt die eigene Recherche als einmalige Momentaufnahme zu betrachten.
