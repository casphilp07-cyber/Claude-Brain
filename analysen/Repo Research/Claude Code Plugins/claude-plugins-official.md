# Claude Plugins Official (anthropics/claude-plugins-official)

**Was es ist:** Anthropics eigenes, offiziell kuratiertes Verzeichnis hochwertiger Claude-Code-Plugins. Seit 22.05.2026 live, ~32,9k Sterne, ~3,7k Forks, gehört Claude Code (ab v2.1.143) standardmäßig als vorkonfigurierte Marketplace an. Laut Marktübersichten inzwischen 100+ gelistete Plugins.

**Kernfunktionen:**
- **`/plugins`**: intern von Anthropic entwickelte und gepflegte Plugins
- **`/external_plugins`**: Drittanbieter-Plugins von Partnern und der Community, die einen Qualitäts-/Sicherheitscheck durchlaufen mussten, um aufgenommen zu werden
- Deckt u.a. LSP-Support für 11 Sprachen, Integrationen (GitHub, Slack, Linear, Supabase, Firebase, Stripe) und Workflow-Tools (feature-dev, commit-commands, pr-review-toolkit) ab
- Wofür einsetzen: erste Anlaufstelle, bevor man Drittanbieter-Marketplaces durchsucht — Qualität/Sicherheit hier am ehesten geprüft (auch wenn Anthropic selbst betont, keine Garantie für jedes gelistete Plugin zu übernehmen)

**Wie man es mit Claude Code nutzt:**
```
/plugin install {plugin-name}@claude-plugins-official
```
Oder interaktiv browsen über `/plugin` → Tab zu "Discover".

**Einschätzung:** Übernehmen als Standard-Startpunkt für jede Plugin-Suche — bevor man ein Drittanbieter-Plugin installiert, lohnt sich immer erst der Blick hierhin.
