# Awesome MCP Servers (punkpeye/awesome-mcp-servers)

**Was es ist:** Die größte und meistgenutzte kuratierte Sammlung von MCP-Servern überhaupt — praktisch das "Hauptverzeichnis" des gesamten MCP-Ökosystems. ~91,7k Sterne, ~13,8k Forks, MIT-Lizenz, sehr aktiv (2.300+ Pull Requests von der Community).

**Kernfunktionen:**
- Riesige, community-gepflegte Liste von MCP-Servern über praktisch alle Kategorien (Datenbanken, Kommunikationsplattformen, Dev-Tools, Cloud-Dienste, u.v.m.)
- Wofür einsetzen: erste Anlaufstelle bei der Frage "gibt es dafür schon einen MCP-Server?" — bevor man selbst einen baut, hier zuerst suchen

**Wie man es mit Claude Code nutzt:** Kein installierbares Paket selbst, sondern ein Index — man sucht den passenden Server in der Liste und bindet ihn dann einzeln über `claude mcp add` bzw. die MCP-Config ein.

**Einschätzung:** Übernehmen als Standard-Nachschlagewerk für MCP-Server — sollte der erste Anlaufpunkt sein, bevor man in dieser Kategorie irgendwo anders sucht.
