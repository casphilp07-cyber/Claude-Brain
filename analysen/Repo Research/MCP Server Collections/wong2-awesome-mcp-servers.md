# Awesome MCP Servers (wong2/awesome-mcp-servers)

**Was es ist:** Eine zweite, kleinere kuratierte MCP-Server-Liste — nützlich als Alternative/Ergänzung, wenn die riesige punkpeye-Liste zu unübersichtlich ist. ~4,2k Sterne, ~1,7k Forks, MIT-Lizenz.

**Kernfunktionen:**
- Kuratierte (statt reine Crowd-Submission-) Auswahl an MCP-Servern
- Wofür einsetzen: schnellerer, handverlesener Überblick statt der sehr großen punkpeye-Liste zu durchforsten

**Wie man es mit Claude Code nutzt:** Wie bei allen Awesome-Listen: gewünschten Server heraussuchen, einzeln per `claude mcp add` einbinden.

**Einschätzung:** Als zweite Referenz nützlich, aber nicht essentiell — punkpeye/awesome-mcp-servers deckt die meisten Fälle bereits ab; diese Liste eher für einen schnelleren, kuratierteren Blick.
