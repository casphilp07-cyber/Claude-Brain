## Top-Empfehlungen
1. **anthropics/skills** zuerst — definiert den Standard, an dem sich alles andere orientiert
2. **ComposioHQ/awesome-claude-skills** als Hauptquelle für die breite Masse an Skills
3. **VoltAgent/awesome-agent-skills**, wenn eine Skill vom Hersteller selbst (statt Community) gewünscht ist
4. **alirezarezvani/claude-skills** gezielt für Business-/Strategie-Skills ergänzen, nicht als Coding-Ersatz

Hinweis: `obra/superpowers` (siehe [[../Claude Code Plugins/superpowers|Claude Code Plugins]]) ist im Kern ebenfalls eine Skill-Library, wird aber primär als Plugin/Methodik installiert und deshalb dort geführt.
