# Claude Skills Collection (abubakarsiddik31/claude-skills-collection)

**Was es ist:** Kleinere, aber sauber kategorisierte Sammlung von 218 Skills über 13 Kategorien. ~885 Sterne — deutlich kleiner als die großen Listen, dafür übersichtlicher und mit klarer Kategorie-Struktur.

**Kernfunktionen:**
- Unterscheidet klar Official Skills (Anthropic: docx, pdf, pptx, xlsx) von Community-Skills
- 13 Kategorien, u.a. Development & Code Tools (72 Skills), Marketing & SEO (20), Writing & Research (20), Security & Testing (13), plus Learning, Design, Career, Data Analysis
- Hinweis: Skills benötigen Claude Pro/Max/Team/Enterprise mit aktivierter Code-Ausführung
- Wofür einsetzen: schneller Überblick, wenn man nicht durch tausende Einträge der großen Listen scrollen will, sondern eine kompakte, thematisch sortierte Auswahl bevorzugt

**Wie man es mit Claude Code nutzt:** Repo klonen, Code-Ausführung + Skill-Loading aktivieren, Skill-Ordner hochladen oder Git-Link mit `SKILL.md` verknüpfen, dann Claude bitten die Skill zu aktivieren.

**Einschätzung:** Nicht relevant als eigenständige Installation (zu klein/überschneidet sich stark mit größeren Listen), aber nützlich als schnelle Referenz, wenn man einen kompakten Kategorie-Überblick sucht statt einer riesigen Liste.
