# Awesome Agent Skills (VoltAgent/awesome-agent-skills)

**Was es ist:** Eine kuratierte Sammlung von 1.000+ (Repo-Beschreibung nennt inzwischen bis zu 1.400) Agent-Skills — mit dem entscheidenden Unterschied zu anderen Listen: die Skills stammen von **offiziellen Entwickler-Teams** großer Firmen, nicht nur aus der Community. ~29,4k Sterne, ~3,2k Forks.

**Kernfunktionen:**
- Skills direkt von Anthropic (Claude), Google Gemini, Vercel, Cloudflare, Netlify, Stripe u.a. offiziellen Teams
- Domänenspezifische Tiefe: z.B. TestMu AI (50+ Test-Automatisierungs-Frameworks), Microsoft (133+ Skills über 6 Sprachen), Sentry (30+ SDK-Setups), Trail of Bits (Security), Hugging Face (ML-Workflows)
- Kompatibel mit Claude Code, Codex, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf und mehr — praktisch, wenn man nicht nur mit Claude Code arbeitet
- Wofür einsetzen: wenn man eine Skill direkt vom Hersteller eines Tools/Frameworks sucht (z.B. "wie richte ich Sentry offiziell ein") statt einer community-geschriebenen Anleitung zu vertrauen

**Wie man es mit Claude Code nutzt:** Skills sind über eine zentrale Registry unter `officialskills.sh/<org>/<repo>/<skill>` abrufbar; ansonsten wie gewohnt als Ordner mit `SKILL.md` in den Skills-Ordner kopieren.

**Einschätzung:** Übernehmen als bevorzugte Quelle, wenn eine offizielle (statt community-erstellte) Skill für ein bestimmtes Tool/Framework gesucht wird — Qualität/Vertrauenswürdigkeit tendenziell höher als bei reinen Community-Listen.
