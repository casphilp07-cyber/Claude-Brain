# Claude Skills — alirezarezvani (alirezarezvani/claude-skills)

**Was es ist:** Eine der umfangreichsten Einzelsammlungen mit 362 produktionsreifen Skills, 70+ Custom Commands und 30+ Agenten-Personas — mit ungewöhnlich starkem Fokus auch auf Business-/Management-Domänen statt nur Coding. ~23,6k Sterne, ~3,3k Forks, MIT-Lizenz.

**Kernfunktionen:**
- 18 Domänen, u.a.: Engineering (52 Kern- + 84 Advanced-Skills: Architektur, DevOps, Security, AI/ML, Testing), Product (17: Strategie, UX-Research, Analytics, SaaS-Scaffolding), Marketing (48 über 8 "Pods": Content, SEO, CRO, Growth), **C-Level Advisory (68 Skills)**, Research, Compliance/Regulatory, Business Operations, Finance, Projektmanagement
- Alle 644 Python-Tools nutzen nur die Standardbibliothek (keine externen Abhängigkeiten) — geringes Risiko beim Ausführen
- Wofür einsetzen: sobald Claude Code nicht nur für Code, sondern auch für Business-/Strategie-Arbeit (z.B. als virtueller CFO/Marketing-Berater) genutzt werden soll — deckt eine Nische ab, die reine Coding-Skill-Listen nicht haben

**Wie man es mit Claude Code nutzt:**
```
/plugin marketplace add alirezarezvani/claude-skills
/plugin install engineering-skills@claude-code-skills
```
Unterstützt insgesamt 13 Plattformen (Claude Code, Codex, Gemini CLI, Cursor, Aider, Windsurf u.a.) über Konvertierungs-Scripts.

**Einschätzung:** Als Plugin installieren, wenn Business-/Strategie-Skills gebraucht werden — für reines Software-Engineering sind die spezialisierteren Listen (VoltAgent, ComposioHQ) meist treffender.
