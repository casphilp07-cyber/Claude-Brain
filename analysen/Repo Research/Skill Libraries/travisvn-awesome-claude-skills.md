# Awesome Claude Skills — travisvn (travisvn/awesome-claude-skills)

**Was es ist:** Eine gut strukturierte, speziell auf Claude Code zugeschnittene kuratierte Skill-Liste, die klar zwischen offiziellen (Anthropic-) und Community-Skills unterscheidet. ~14,5k Sterne, ~1,8k Forks.

**Kernfunktionen:**
- **Official Skills**: Dokumentenbearbeitung (docx, pdf, pptx, xlsx), Design-Tools (algorithmic-art, canvas-design), Dev-Utilities (frontend-design, mcp-builder), Kommunikationshilfen
- **Community Skills**: z.B. iOS-Simulator-Automatisierung, Web-Fuzzing-Anleitungen, Browser-Automatisierung, wissenschaftliche Tools
- **Collections**: verlinkt u.a. `obra/superpowers` als eigene Kategorie großer Bibliotheken
- Wofür einsetzen: guter Mittelweg zwischen der riesigen ComposioHQ-Liste und kleineren Nischen-Listen — übersichtlich genug, um schnell die relevante Skill zu finden

**Wie man es mit Claude Code nutzt:**
```
/plugin marketplace add [skill-name]
```
oder lokal: `/plugin add /path/to/skill-directory`. Auch über die Web-Oberfläche nutzbar (Settings → Capabilities → Skills aktivieren, dann Skill hochladen/browsen).

**Einschätzung:** Als Plugin installieren — gute Balance aus Übersichtlichkeit und Abdeckung, sinnvoll als zweite Anlaufstelle neben der offiziellen Anthropic-Liste.
